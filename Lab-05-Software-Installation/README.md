# Lab 5: Installing Notepad++

## Objective

Install Notepad++ on a Windows computer and verify that the application installs and launches successfully. This lab simulates a common Help Desk request to install approved software for a user.

---

## Ticket

**Ticket Number:** 0005

**Issue:** A user needs Notepad++ installed for editing text files, configuration files, and code.

**Priority:** Low

**Status:** Completed

---

## Steps Performed

1. Downloaded the latest 64-bit Notepad++ installer from the official Notepad++ website.
2. Verified the installer downloaded successfully.
3. Opened the installer and approved the Windows User Account Control (UAC) prompt.
4. Selected the English language for the installation.
5. Accepted the Notepad++ License Agreement.
6. Left the default installation location (`C:\Program Files\Notepad++`).
7. Kept the default installation components.
8. Started the installation process.
9. Waited for the installation to complete successfully.
10. Launched Notepad++ after the installation finished.
11. Opened Windows **Settings > Apps > Installed Apps** and confirmed that Notepad++ was listed as an installed application.

---

## Verification

The installation was verified by completing the following checks:

- ✅ The installer completed without any errors.
- ✅ Notepad++ launched successfully.
- ✅ The application appeared in the Windows Installed Apps list.
- ✅ The application was ready for use.
