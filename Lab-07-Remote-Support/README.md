# Lab 7: Remote Support & Remote Desktop

## Objective

Understand the basics of remote support, evaluate Windows remote access capabilities, and document troubleshooting steps when preparing a computer for remote assistance.

---

## Ticket

**Ticket Number:** 0007

**Issue:** User needs remote assistance with their Windows computer.

**Priority:** Medium

**Status:** Completed

---

## Scenario

A user working remotely needs assistance with their Windows computer. As the Help Desk technician, I reviewed the available remote support options and checked whether Remote Desktop functionality was available on the system.

---

## Troubleshooting Steps

1. Opened Windows Settings and navigated to Remote Desktop settings.
2. Reviewed the Remote Desktop availability status.
3. Identified that the computer is running Windows 11 Home Edition.
4. Verified that Windows 11 Home does not support Remote Desktop hosting.
5. Researched alternative remote support options.
6. Reviewed Windows Quick Assist as an alternative solution for remote assistance.
7. Documented findings and system limitations.

---

## Resolution

Remote Desktop hosting was unavailable because the computer is running Windows 11 Home Edition. The limitation was identified and documented.

Alternative remote support options, such as Windows Quick Assist and third-party remote support tools, can be used to assist users remotely.
