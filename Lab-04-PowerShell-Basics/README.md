# Lab 4: PowerShell Basics

## Objective

The goal of this lab is to practice basic PowerShell commands used by IT Help Desk technicians for system information gathering and troubleshooting.

## Tasks Completed

- Opened PowerShell
- Gathered system information
- Viewed running processes
- Checked services
- Practiced basic commands

## Tools Used

- Windows PowerShell

## Commands Practiced

### Get-ComputerInfo

Purpose:
Displays detailed computer information.

### Get-Process

Purpose:
Shows running applications and processes.

### Get-Service

Purpose:
Shows Windows services and their status.

## Skills Practiced

- PowerShell basics
- Windows administration
- System troubleshooting
- Command-line tools
