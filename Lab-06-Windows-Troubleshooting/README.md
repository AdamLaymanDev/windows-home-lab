# Lab 6: Windows Troubleshooting

## Objective

Investigate and troubleshoot a Windows computer that is running slowly by checking system performance, startup applications, storage, and Windows Update status. This lab simulates a common Help Desk support ticket.

---

## Ticket

**Ticket Number:** 0006

**Issue:** User reports the computer is running slowly.

**Priority:** Medium

**Status:** Completed

---

## Troubleshooting Steps

1. Opened Task Manager to review current system performance.
2. Checked running processes for applications consuming high CPU, memory, or disk resources.
3. Reviewed startup applications to identify programs that could slow boot times.
4. Checked available storage space to ensure sufficient free disk space.
5. Verified Windows Update status to determine if pending updates could affect system performance.
6. Observed overall system performance during normal operation.
7. Documented findings and confirmed the system was functioning as expected.

---

## Resolution

No critical performance issues were identified during the troubleshooting process. CPU, memory, and disk usage were within normal operating ranges. Startup applications were reviewed, available storage space was confirmed, and Windows Update status was checked. The system was determined to be operating normally at the time of testing.

---

## Skills Learned

During this lab I practiced the following Help Desk skills:

- Troubleshooting Windows performance issues
- Using Task Manager to monitor system resources
- Identifying resource-intensive applications
- Reviewing startup applications
- Checking available storage space
- Verifying Windows Update status
- Following a structured troubleshooting process
- Documenting troubleshooting findings
